## 16 OneStop AI Assistant – Special Capabilities

The AI Assistant is not merely another tool. It acts as the main natural-language interface to the OneStop tool ecosystem.

It should be able to:

- Identify which OneStop tool is required.
- Execute multiple tools sequentially.
- Combine tools into workflows.
- Process uploaded files.
- Explain how to accomplish a task.
- Redirect users to the appropriate OneStop tool.
- Detect when OneStop cannot perform a requested task.
- Recommend external solutions.
- Separate recommendations into Free and Paid.
- Provide the external website link.
- Explain relevant limitations.
- Suggest alternative OneStop workflows where possible.

Example request:

> "Convert this PDF to Excel, remove the first sheet, then create a QR code for the result."

The assistant should execute the whole chain instead of forcing the user to visit multiple separate tools manually.

## Final Scope Note

This document represents the current master feature list for OneStop. Individual tools may be deferred, removed, or implemented in later phases based on implementation complexity, offline feasibility, legal/platform constraints, or practical usefulness. The overall product architecture should remain modular so that tools can be added or removed without redesigning the core application.
